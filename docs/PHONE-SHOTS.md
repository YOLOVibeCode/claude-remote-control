# Phone screenshots

`ARTICLE.md` uses three phone-sized screenshots of **claude.ai/code**, taken in Chrome at
iPhone 16 Pro size against a live `my-app` demo session:

| File | Shows |
|------|-------|
| `phone-a-session-list.png` | The session list with `my-app` at the top of Recents. Every other session is blurred |
| `phone-b-session.png` | A prompt typed on the phone, run on the Mac (`Hello from my Mac`) |
| `phone-c-environment.png` | New session → Remote Control → the Mac running `ccserve` |

To use real Claude app captures instead, save them under the same file names. Before you
publish any capture:

- Hide or crop **session URLs, QR codes and IDs** (`session_…`, `env_…`).
- Blur or crop other sessions whose names give away private projects.
- Crop out notification banners, the carrier name and your email or avatar.
